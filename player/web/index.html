DS Player

Plays Nintendo DS games in the browser with the melonDS core, compiled to WebAssembly. Pick a .nds file to start. The file is read locally by your browser and never uploaded.

Controls

D-pad Arrow keys
A / B / X / Y X / Z / S / A
L / R Q / W
Start / Select Enter / Backspace
Touch screen Click or drag on the bottom screen
Fast-forward Hold Tab
Layout / Smoothing F2 / F4
Reset Ctrl+R

Gamepads work too: the right face button is A, as on the DS.
